## About

This repository collects coded answers for C programming questions, including common exercises and self-created practice problems. It is meant for strengthening syntax, loops, arrays, functions, pointers, and general problem-solving in C.

## Repository Map

- `Answers/`: individual `.c` solutions.
- `Ouestions/`: question prompts used for the answer files.

## Compile A Program

```bash
gcc Answers/1.c -o program
./program
```


## Getting Started

Clone the repository:

```bash
git clone https://github.com/CoderFatherBB/C_Programming.git
cd C_Programming
```

Open the folder or notebook you want to explore. Most directories are self-contained, so start from the local `README.md`, source file, notebook, or project folder for that topic.
